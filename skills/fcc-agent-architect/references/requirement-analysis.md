# Agent Requirement Analysis

## Purpose
Identify expertise gaps in the FCC module based on new regulatory requirements or business domains.

## Workflow

1. **Intake:** User provides a new regulatory document, regulation name (e.g., "MiCA"), or a business challenge.
2. **Analysis:**
    - Scan current FCC module agents (KYC, Sanctions, etc.).
    - Identify specific regulatory obligations in the input.
    - Map obligations to existing agent capabilities.
3. **Outcome:**
    - If a gap exists: Recommend a new specialized agent or an expansion of an existing one.
    - Provide a high-level "Expertise Profile" for the recommendation.

## Expertise Profile Template
- **Domain:** [e.g., Crypto-asset service provider regulation]
- **Key Obligations:** [List 3-5 critical regulatory tasks]
- **Expertise Gap:** [Why current agents cannot handle this]
- **Recommendation:** [New Agent Name / Existing Agent Update]
